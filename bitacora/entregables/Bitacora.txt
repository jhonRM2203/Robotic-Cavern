  El proceso seguido para crear los mapas de niveles con Tiled fue:

  CÓMO SE CREARON LOS MAPAS CON TILED MAP EDITOR:

  ¿Qué es Tiled?
    Tiled es un editor de mapas 2D gratuito que permite diseñar niveles para
    videojuegos usando bloques de terreno (llamados "tiles" o "tilesets").
    Los mapas que se diseñan en Tiled se pueden exportar y usar en cualquier
    motor de videojuegos, incluyendo GDevelop.

  ¿Qué es un tileset?
    Un tileset (mapa de tejas) es una imagen que contiene varios trozos de
    terreno o elementos decorativos. A partir de esa imagen se van colocando
    los bloques para construir el nivel.

  Paso 1 — Crear un proyecto en Tiled:
    Al abrir Tiled, se crea un nuevo proyecto (New Project). El proyecto
    agrupa todos los mapas y tilesets del juego en un solo lugar.
    Se creó una carpeta llamada "mi plataforma" para guardar todos los
    archivos de los niveles del juego.

  Paso 2 — Crear un nuevo mapa:
    Se crea un nuevo mapa (New Map). Las configuraciones usadas fueron:
    - Orientación: Ortogonal (cuadrículas cuadradas, el estilo más común
      para juegos de plataformas)
    - Tamaño de cada bloque: 25 x 25 píxeles (para que coincida con los
      sprites de los bloques del juego)
    - Tamaño del mapa: el número de bloques de ancho y alto del nivel

  Paso 3 — Agregar el tileset:
    Se cargó la imagen que contiene los bloques del juego (block0 a block3).
    Se configuró el tamaño de cada bloque (25x25 px) y los márgenes entre
    ellos. Esto permite que Tiled divida la imagen correctamente en bloques
    individuales listos para usar.

  Paso 4 — Diseñar el nivel:
    Con las herramientas de Tiled se fue construyendo el nivel:
    - Brocha de estampar: para colocar bloques uno a uno
    - Herramienta de relleno: para llenar áreas grandes rápidamente
    - Goma de borrar: para corregir errores
    Se usaron capas separadas para el suelo, las plataformas y los límites
    del nivel. Trabajar con capas permite modificar cada parte sin afectar
    las demás.

  Paso 5 — Agregar colisiones:
    En el editor de tilesets de Tiled se configuraron las máscaras de colisión
    de cada bloque. Este paso es muy importante: le indica al motor de juego
    (GDevelop) cuáles bloques son sólidos y cuáles no.
    Se seleccionaron todos los bloques a la vez y se aplicó la colisión
    automática (Detect Bounding Box). También se les asignó la clase
    "plataforma" para que GDevelop los reconociera correctamente.

  Paso 6 — Exportar en formato JSON:
    El mapa se exportó en formato JSON (Archivo → Exportar como → JSON).
    Este formato es el que GDevelop puede leer directamente.
    Cada nivel generó dos archivos: el mapa (.tmj / .json) y el tileset (.tsj).

  Paso 7 — Importar a GDevelop:
    En GDevelop se creó un objeto de tipo "Tilemap", se apuntó al archivo
    JSON exportado y se le agregó el comportamiento "Obstáculo de plataforma"
    para que el jugador pudiera caminar sobre los bloques.

PROBLEMA ENCONTRADO:
  En el dispositivo Android, los botones táctiles eran muy pequeños y estaban
  mal posicionados. En algunos ángulos de la pantalla era imposible presionar
  el botón de salto y el de disparo al mismo tiempo.

  Se aumentó el tamaño de todos los botones táctiles y se redistribuyeron
  por la pantalla. El pad de movimiento quedó en la parte inferior izquierda
  y los botones de acción en la inferior derecha, dejando suficiente espacio
  entre ellos.

PROBLEMA ENCONTRADO:
  Al compilar el APK, el proceso fallaba por culpa de los nombres de archivo
  con tildes y caracteres especiales (como "Caverna Cibernética de Neón.png").
  Los sistemas Android no aceptan bien esos caracteres en los nombres de archivos.

SOLUCIÓN:
  Se creó un script (.bat) que automáticamente renombra los archivos con
  caracteres especiales y actualiza las referencias dentro del proyecto
  antes de compilar. Después de correr el script, la compilación del APK
  funcionó correctamente.
