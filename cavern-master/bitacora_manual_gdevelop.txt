PARTE 7 — IMPLEMENTACIÓN EN GDEVELOP (MANUAL TÉCNICO)
================================================================================

--------------------------------------------------------------------------------
7.1  CONFIGURACIÓN INICIAL DEL PROYECTO
--------------------------------------------------------------------------------
  Paso 1 — Crear proyecto nuevo:
    - Abre GDevelop 5.
    - Haz clic en "Crear un nuevo proyecto".
    - Elige "Proyecto vacío".
    - Configura: Nombre del juego → [____________________]
    - Configura: Resolución → [____] × [____] px.
    - Guarda el proyecto en tu carpeta de trabajo.

  Paso 2 — Crear las escenas:
    - En el panel izquierdo, haz clic en el ícono "+" junto a "Escenas".
    - Crea una escena por cada pantalla de tu juego (ver sección 5).
    - Nombra cada escena de forma clara: "Menu", "Juego", "GameOver", etc.

  Paso 3 — Importar los recursos:
    - En la pestaña "Recursos del proyecto", arrastra tus imágenes y sonidos.
    - Organiza los recursos en carpetas con el mismo nombre que tus escenas.


--------------------------------------------------------------------------------
7.2  CREAR EL PERSONAJE JUGADOR
--------------------------------------------------------------------------------
  Paso 1 — Agregar objeto sprite:
    - En la escena de juego, haz clic en "Agregar objeto" → "Sprite".
    - Nombra el objeto: [__________] (ej. "Jugador").

  Paso 2 — Agregar animaciones:
    - En el editor del objeto, haz clic en "+" para agregar animación.
    - Nombre de la animación: [__________] (ej. "Correr").
    - Importa los frames correspondientes (ver sección 6.2).
    - Ajusta la velocidad de la animación: [____] FPS.
    - Repite para cada animación (quieto, correr, saltar, etc.).

  Paso 3 — Agregar comportamiento de plataforma:
    - En la pestaña "Comportamientos" del objeto, haz clic en "+".
    - Selecciona "Platform character" (Personaje de plataformas).
    - Configura:
        Velocidad máxima          : [____] px/s
        Velocidad de salto        : [____] px/s
        Gravedad                  : [____] px/s²

  Paso 4 — Agregar variables de objeto:
    - En la pestaña "Variables" del objeto, agrega:
        HP      → tipo: número → valor inicial: [____]
        Vidas   → tipo: número → valor inicial: [____]
        Mirando → tipo: cadena → valor inicial: "derecha"


--------------------------------------------------------------------------------
7.3  CREAR LAS PLATAFORMAS Y EL NIVEL
--------------------------------------------------------------------------------
  Opción A — Tiles / Tilemap (recomendado para niveles con grilla):
    - Agrega un objeto "Tilemap" a la escena.
    - Importa tu hoja de tiles (tileset) en los recursos.
    - Dibuja el nivel con el editor de tiles de GDevelop.
    - Agrega comportamiento "Platform" a cada tile sólido.

  Opción B — Sprites individuales:
    - Agrega un objeto sprite para el bloque/plataforma.
    - Agrega comportamiento "Platform" al objeto.
    - Duplica y posiciona los bloques para armar el nivel.

  >> Para que el jugador colisione con la plataforma, el objeto plataforma
  >> DEBE tener el comportamiento "Platform" y el jugador "Platform character".

  Paso 3 — Agregar íconos de vida (si usas sprites):

    - Usa un evento para mostrarlo u ocultarlo según la variable Vidas.

================================================================================
GLOSARIO RÁPIDO DE TÉRMINOS GDEVELOP
================================================================================

  Escena (Scene)    : Pantalla o estado del juego (Menú, Juego, GameOver...).
  Objeto (Object)   : Elemento del juego (jugador, bloque, enemigo, texto...).
  Sprite            : Objeto con imagen o animación.
  Comportamiento    : Lógica predefinida que se agrega a un objeto
                      (Platform character, Physics, etc.).
  Evento (Event)    : Bloque de lógica: CONDICIÓN → ACCIÓN.
  Condición         : El "cuándo" de un evento (tecla presionada, colisión...).
  Acción            : El "qué hacer" de un evento (mover, reproducir sonido...).
  Variable global   : Variable accesible desde cualquier escena (Puntaje, Vidas).
  Variable de objeto: Variable que pertenece a un objeto específico (HP, Nombre).
  Capa (Layer)      : Nivel de profundidad visual. Útil para el HUD (capa fija).
  Tilemap           : Mapa creado con tiles (baldosas) para construir niveles.
  Platform          : Comportamiento de superficie sobre la que se puede caminar.
  Expresión         : Fórmula para mostrar o calcular valores en GDevelop,
                      ej. ToString(Variable(Puntaje)).
  FPS               : Fotogramas por segundo — velocidad de animación.
  Hitbox            : Área de colisión de un objeto.
  HUD               : Interfaz en pantalla (puntaje, vidas, etc.).
